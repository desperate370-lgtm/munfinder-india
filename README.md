# Ferrari Cinematic Landing Page

Ultra-premium, futuristic Ferrari marketing website built with plain HTML/CSS/JS.

## Launch (working)

From this repository root:

```bash
./launch.sh
```

Then open:

- http://127.0.0.1:4173/index.html

## Alternative launch

```bash
python -m http.server 4173 --directory /workspace/munfinder-india
```

## Files

- `index.html` – page structure and content sections
- `styles.css` – luxury visual system, animations, responsive design
- `script.js` – navbar/reveal/parallax/configurator interactions
- `launch.sh` – one-command local launch script
